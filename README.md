# LangGraph Learning Journey

This repository contains my hands-on journey learning LangGraph and building agentic AI workflows with Python.

## What I am learning

- Building workflows with LangGraph nodes and edges
- Connecting language models with prompts and tools
- Managing state across multiple workflow steps
- Creating reusable patterns for chaining, reviewing, and decision-making
- Designing practical AI agents that can solve tasks step by step

## Examples

The notebooks cover workflows such as BMI calculation, simple LLM calls, prompt chaining, cricket analysis, UPSC essay writing, and review-reply generation.
